Install Cetas first — the npm build is recommended: it is the most stable part
of this project and the one really used in production — then follow the guide
to your first message.

## New to coding agents?

You do not need any programming experience from here. Cetas is an assistant
that runs on your own machine: you state what you want, it reads and edits
files and runs commands, showing you every step. You need four things:

1. A macOS, Linux, or Windows computer;
2. A [terminal](/en/getting-started/glossary/#terminal) — the typing window
   where Cetas lives;
3. [Node.js](/en/getting-started/glossary/#nodejs) — the engine that runs it;
4. An account with a model [provider](/en/getting-started/glossary/#provider)
   (say DeepSeek or OpenAI); first-time users create an
   [API key](/en/getting-started/glossary/#api-key) on their site.

If you are still deciding, read [Is Cetas for me?](/en/faq/is-cetas-for-me/).
Ready? Head straight to
[Installation & First Run](/en/getting-started/installation/) — it starts from
zero and every term links to an explanation.
