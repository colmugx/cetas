<Aside type="note">
默认推荐 Cetas JS。Native 是另一种 Go/Bubble Tea 终端，使用相同的 MoonBit Agent 内核，但两者的功能并不完全一致。
</Aside>

## 方案一：通过 npm 安装 Cetas JS（推荐）

```bash
npm install -g @posoco/cetas
cetas --version
```

需要 Node.js 24 或更高版本（[nodejs.org](https://nodejs.org/)）。这是默认推荐的交互式终端，包含 Board 等 JS 专属集成。当前稳定 Cetas 发布版通过 npm 分发 JS 终端，不再把 `cetas-bun` 直接下载包作为首选入口。

## 方案二：Cetas Native（无需 Node.js）

Native 使用 Go/Bubble Tea v2 实现终端，底层同样运行 MoonBit Cetas/Posoco。它是第二种实现，不承诺与 JS 完全相同的功能。

### Homebrew：macOS Apple Silicon / Linux x64

```bash
brew install colmugx/tap/cetas
```

### Scoop：Windows x64

```powershell
scoop bucket add cetas https://github.com/colmugx/scoop-bucket
scoop install cetas/cetas
```

### 直接安装或下载

也可以使用仓库中的 [Unix 安装脚本](https://github.com/colmugx/cetas/blob/main/install.sh) 或 [PowerShell 安装脚本](https://github.com/colmugx/cetas/blob/main/install.ps1)。它们会先显示检测到的系统、版本、目标目录和文件清单，得到终端确认后才下载二进制。非交互场景需明确指定 `--yes`（Unix）或 `-Yes`（PowerShell）。

手工下载请在 [GitHub Releases](https://github.com/colmugx/cetas/releases) 选择 `cetas-v*` 版本（Memoh 使用独立版本系列）。当前 Native 支持 macOS ARM64、Linux x64 和 Windows x64。Windows 的 `cetas-windows-x64.zip` 含三个 EXE 和 `cetas_moon.dll`；**DLL 必须与 `cetas.exe` 放在一起**。

## 只需要编辑器 ACP 或一次性 Runner？

每个 Cetas Release 都继续保留**可独立下载**的资产：

| 用途 | 独立发布文件 |
| --- | --- |
| Lody、Zed 等 ACP 客户端 | `cetas-acp-darwin-arm64.tar.gz`、`cetas-acp-linux-x64.tar.gz`、`cetas-acp-windows-x64.zip` |
| 脚本/CI 的一次性任务 | `cetas-run-darwin-arm64.tar.gz`、`cetas-run-linux-x64.tar.gz`、`cetas-run-windows-x64.zip` |

这两种用途不必下载整个 Native 终端。校验文件使用同一个 Release 的 `SHA256SUMS`。

## JS 与 Native 同时安装

两者都可能提供 `cetas` 命令，Shell 会运行 `PATH` 中排在前面的那一份。Unix 用 `command -v cetas`，PowerShell 用 `Get-Command cetas` 检查。配置共享 [Cetas Home](/configuration/cetas-home/)，但功能、确认界面和会话流程不保证一致。

## 从装好到第一条消息

四步。

### 1. 在你的项目目录里启动

```bash
cd /path/to/your/project
cetas
```

它读、改、执行的每一样东西都相对这个目录。还没有项目？新建一个空文件夹，进去一样能开始。

### 2. 登录一家供应商

Cetas 不带模型，调用的是供应商（DeepSeek、OpenAI 这类提供模型的公司）的接口。去供应商官网注册账号、建一个 API key，然后：

```text
/login
```

选供应商，粘贴 key（或走它支持的浏览器授权），完成。列表比你预期的短？见[供应商](/configuration/providers/)。

### 3. 选一个模型

```text
/model
```

列表来自你刚登录的供应商，选一个就能用了。

### 4. 说第一句话

```text
这个仓库的鉴权是怎么工作的？
```

没有仓库也一样，说什么都行——它能流式回答，就算通了。第一天用得上的几个键：

- `@路径` 挂一个工作区文件，<kbd>Tab</kbd> 补全；
- <kbd>Esc</kbd> 打断当前回合，运行中接着打字会排队；
- 完全信任它之前，`/permission readonly` 先把会话降到只读，见[权限](/configuration/permissions/)；
- `/help` 列出这份构建真正有的命令。

会话自动保留：`/sessions` 随时重开，`/rewind` 退回出错之前——没有"保存"这一步。

## 要用自己公司的端点？

Cetas 原生支持私有化部署的 OpenAI 兼容端点，走法在[自定义模型](/configuration/custom-models/)。

## 卡住了

| 现象 | 处理 |
| --- | --- |
| 安装时报 Node 版本太旧 | 升级 Node，或改用发布制品 |
| `/login` 或 `/model` 列表是空的 | 重新 `/login` 再 `/model`；还不行见[供应商](/configuration/providers/) |
| 第一句话就报错 | 多半是登录没完成，重来一遍 `/login` |
| 说什么都被拒绝 | 权限在只读档，`/permission workspace_write` 放开写入 |

登录的凭据、选好的模型、聊过的会话，都自动收在一个 home 目录里，平时不用管；好奇它长什么样、怎么备份，见 [Cetas Home](/configuration/cetas-home/)。
