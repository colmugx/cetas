建议先用 npm 安装 Cetas JS；如果不想安装 Node.js，也可以通过 Homebrew/Scoop 安装 Native。两种终端使用相同 Agent 内核，但宿主功能不同。接着按教程完成第一次对话。

## 第一次接触编码 agent？

从这里开始不需要任何编程经验。Cetas 是装在你自己电脑上的助手：你说需求，它读文件、改文件、执行命令，每一步都看得见。你只需要四样东西：

1. 一台 macOS、Linux 或 Windows 的电脑；
2. [终端](/getting-started/glossary/#终端)—— Cetas 住的那个打字窗口；
3. [Node.js](/getting-started/glossary/#nodejs) 24+ —— 推荐的 JS 版本需要，Native 不需要；
4. 一个[模型供应商](/getting-started/glossary/#供应商provider)的账号（比如 DeepSeek 或 OpenAI），第一次用去官网注册、建一个 [API key](/getting-started/glossary/#api-key)。

拿不准它适不适合自己？先看[「Cetas 适合我吗？」](/faq/is-cetas-for-me/)。准备好了就直接进[安装与首次运行](/getting-started/installation/) —— 那一页从零开始，出现的每个术语都有解释。
