先把 Cetas 装上 —— 推荐用 npm 上那份，它是整个项目里最稳、真正被用于生产的构建 —— 然后按教程一路走到发出第一条消息。

## 第一次接触编码 agent？

从这里开始不需要任何编程经验。Cetas 是装在你自己电脑上的助手：你说需求，它读文件、改文件、执行命令，每一步都摊开给你看。你只需要四样东西：

1. 一台 macOS、Linux 或 Windows 的电脑；
2. [终端](/getting-started/glossary/#终端)—— Cetas 住的那个打字窗口；
3. [Node.js](/getting-started/glossary/#nodejs)—— 让它跑起来的引擎；
4. 一个[模型供应商](/getting-started/glossary/#供应商provider)的账号（比如 DeepSeek 或 OpenAI），第一次用去官网注册、建一个 [API key](/getting-started/glossary/#api-key)。

先问自己一个问题的，看[「Cetas 适合我吗？」](/faq/is-cetas-for-me/)。准备好了就直接进[安装与首次运行](/getting-started/installation/) —— 那一页从零开始，出现的每个术语都有解释。
