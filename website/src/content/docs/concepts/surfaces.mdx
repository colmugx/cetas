Cetas 有三种**使用场景**——终端、编辑器和自动化；其中终端有 **JS 和 Native 两种实现**。默认推荐 npm 发布的 Cetas JS，Native 则是 Go/Bubble Tea 终端的第二选择，两者共享 MoonBit Cetas/Posoco 内核。

| 实现 / 入口 | 交互方式 | 安装或分发 |
| --- | --- | --- |
| **终端 · JS（首选）** `cetas-js` | 功能完整的交互式终端，包括 Board 等 JS 专属功能 | `npm install -g @posoco/cetas` |
| **终端 · Native（第二选择）** `cetas-native` | Go/Bubble Tea v2，功能依宿主实现而不同 | Homebrew（macOS/Linux）、Scoop（Windows）或[发布文件](/getting-started/installation/) |
| **编辑器 · ACP** `cetas-acp` | stdio ACP 服务，适配 Lody、Zed | 单独下载 `cetas-acp-*` |
| **自动化 · Run** `cetas-run` | 每进程一个任务 | 单独下载 `cetas-run-*` |

## 共享的部分

各入口基于相同的内核，通常共享 [Cetas Home](/configuration/cetas-home/) 下的供应商设置、凭据和会话文件，但**不代表** UI 或跨入口会话操作完全一致。

## 不同的部分

- JS 是功能覆盖最完整的终端；Pi/Node/Bun 集成及 Board 工作流目前不在 Native 中。
- Native 使用 Go 终端和 MoonBit Runtime（Unix 静态桥接，Windows 相邻 DLL），不需要 Node.js。
- ACP 单独服务于编辑器，由编辑器负责交互和审批 UI；无需安装完整 Native 就能使用。
- Run 专为脚本/一次性任务设计，也能单独下载。
- JS 和 Native 都可能注册名为 `cetas` 的命令，取决于 `PATH` 的先后顺序。

跨入口续接会话并不是受支持的契约。各平台安装方式见[安装与首次运行](/getting-started/installation/)。
