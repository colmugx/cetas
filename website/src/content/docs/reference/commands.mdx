斜杠命令是确定性的那条路：立即执行，不经过模型回合。`/help` 才是你手上这份构建的权威 —— 本页讲的是其中值得记住的那些。

## 会话与历史

| 命令 | 作用 |
| --- | --- |
| `/new` | 开一个新会话 |
| `/sessions` | 浏览并续接历史会话 |
| `/rewind` | 把这次对话退回到更早的某条消息 |
| `/resume` | 续接本会话被中断的那个回合 |
| `/compact` | 压缩当前上下文 |

`/rewind` 是那个"救命键"：一个回合搞砸了，退回到它之前，而不是跟模型反复解释。

## 模型与供应商

| 命令 | 作用 |
| --- | --- |
| `/login` | 认证供应商（API key 或 OAuth） |
| `/model` | 选对话模型，以及它的推理档位 |
| `/decision` | 选决策模型 —— 和 `/model` 相互独立 |
| `/effort` | 选当前模型的推理档位 |
| `/manager` | 在供应商集合与 Magpie 之间切换 |
| `/quota` | 显示当前管理器的配额信息 |
| `/status` | 显示 agent、会话、模型与管理器状态 |

## 权限与上下文

| 命令 | 作用 |
| --- | --- |
| `/permission` | 设置本会话的权限姿态 —— 见[权限](/configuration/permissions/) |
| `/ptc` | 选择程序化工具调用模式 |
| `/skills` | 按作用域浏览已发现的技能 |

## 干活

| 命令 | 作用 |
| --- | --- |
| `/questions` | 查看待回答的问题并回答一个 |
| `/answer` | 就地回答待答问题：`/answer @q3 是` |
| `/goal` | 启动、查看、暂停或恢复一个带验收的目标 |
| `/board` | 在浏览器里打开 Board 看板（未开启工作流时会询问是否开启） |
| `/board.stop` | 停掉所有本地 Board 服务 |

## 杂项

| 命令 | 作用 |
| --- | --- |
| `/update` | 检查并安装更新 —— 只支持 npm 安装 |
| `/pi` | 管理 pi 包 |
| `/exit`、`/quit` | 退出 |

<Aside type="note" title="不是每份构建都有全部命令">
`/effort`、`/permission`、`/decision`、`/help` 来自组合进来的扩展，所以没有该能力的构建就不会提供它们。上面由 shell 自己拥有的命令则始终存在。`/help` 反映的是真实集合。
</Aside>

## 按键

| 按键 | 效果 |
| --- | --- |
| <kbd>Esc</kbd> | 打断当前回合（若有待审批，先拒绝它） |
| <kbd>Esc</kbd> <kbd>Esc</kbd>（空闲时） | 第一次清空输入，第二次打开 `/rewind` |
| 运行中按 <kbd>Enter</kbd> | 把输入的内容作为后续消息排队 |
| <kbd>Tab</kbd> / <kbd>Enter</kbd> | 应用高亮的 `@path` 补全 |
| <kbd>Ctrl</kbd>+<kbd>T</kbd> | 折叠 / 展开思考块 |
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | 折叠 / 展开工具输出 |

如果 agent 在问你问题，直接打字回复即可 —— `/questions` 和 `/answer` 是给"想从几个里挑一个"的场景用的。

`/permission <mode>` 在回合进行中也能用，值得记住的就是这一条：会话做得比你预期多时，它是随时踩刹车的方式。
