Cetas configuration is shared through the Cetas home, normally `~/.cetas/`.

The central settings file is:

```text
~/.cetas/settings.json
```

It holds provider configuration plus the persisted active model selection. Provider settings are deliberately delegated to provider extensions rather than normalized into one universal provider schema — see [Providers](/configuration/providers/) and [Models](/configuration/models/).

Related durable state includes credentials, MCP configuration, the model-list cache, sessions, and debug output. [Cetas Home](/configuration/cetas-home/) lists the current layout.

Because that directory is shared, every host reads the same configuration. Sharing settings and storage does **not** guarantee identical command flows or cross-host conversation resume — each host page states what it currently supports.
