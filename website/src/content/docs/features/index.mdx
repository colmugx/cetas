## 出厂就在的地基

另有一批能力不单独开页，这里一并交代。

权限有五档。`readonly` 到 `yolo` 之间，值得注意的是 `auto`：每个非只读调用交给决策模型逐次判定，有风险的拦下，安全的放行，全程不用人守。它要求先配好决策模型，否则拒绝开启。见[权限](/configuration/permissions/)。

计划模式在批准之前不会写入任何内容。

技能按三层展开，目录里只带元数据，正文激活时才读。装十个技能，提示不会跟着膨胀十份。

会话全程落盘。`/sessions` 翻历史，`/rewind` 退回出错前，重启接着聊。

工具面里有 astgrep。它按代码结构搜，重构前问"这个接口还有哪里在用"，得到的是调用点。

## 建议的上手顺序

1. [选模型](/features/model-selection/)，成本和质量都在这一步定。
2. [子代理](/features/subagents/)，从只读的活开始，风险最低。
3. [Board](/features/board/)，流程稳定后再上，那时你在管一条流水线。

更多问题见[问答](/faq/)。
