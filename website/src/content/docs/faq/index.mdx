按起点挑着看：

- [Cetas 适合我吗？](/faq/is-cetas-for-me/) — 不写代码的个人创作者、正在转型的程序员、想读源码的极客，各自的起点需要准备什么。
- [Cetas 和其他编码 agent 有什么不同？](/faq/how-different/) — 四条结构性差异，什么时候值得换，什么时候先别换。
- [为什么 Cetas 没有内置 Caveman？](/faq/why-doesnt-bundle-caveman/) — caveman 的六块功能里，cetas 哪些有对应实现，哪些没有，以及怎么把 caveman 的技能直接装进来用。
- [为什么现在不带 rtk 了？](/faq/why-no-rtk/) — cetas 集成过 rtk；一份独立实测解释了截断信息的真实代价，以及想用时怎么接回去。
