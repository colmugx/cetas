`cetas-acp` exposes Cetas over the Agent Client Protocol. It composes the same `cetas-core` used by the other hosts.

## Build

```bash
cd cetas-acp
moon build --target native --release
```

MoonBit writes the native binary to the workspace build output for `colmugx/cetas-acp/main/main.exe`. A released archive is also available — see [Installation](/getting-started/installation/).

## Connect your editor

A provider must already be configured before the ACP host can serve prompts, so run `/login` and `/model` in the terminal host first.

For current Zed versions, add a top-level `agent_servers` entry to your settings:

```json
{
  "agent_servers": {
    "Cetas": {
      "type": "custom",
      "command": "/absolute/path/to/cetas-acp",
      "args": [],
      "env": {}
    }
  }
}
```

Use `cetas-acp.exe` on Windows. If your editor version expects a different schema, follow [Zed's custom-agent instructions](https://zed.dev/docs/ai/external-agents#custom-agents).

Launch Cetas with the project as its working directory — coding tools operate on the process working directory.

## Session configuration

ACP advertises session config options for:

- `model` — a successful change is persisted as the next launch's selection.
- `effort` — persisted when the active model exposes reasoning-effort choices.
- `permission` — runtime-only and session-scoped; deliberately not persisted.

Changes arrive through `session/set_config_option`. For connection failures, inspect the editor's ACP logs and the agent's stderr.

## Environment

| Variable | Effect |
| --- | --- |
| `CETAS_PERMISSION_MODE` | Startup posture: `readonly`, `workspace_write`, `interactive`, `auto`, or `yolo`. Unset means `yolo`; an unrecognized value emits one warning and falls back to `workspace_write`. |
| `CETAS_MCP_MODE=eager` | Connect configured MCP servers at startup instead of lazily on the first turn. |
| `CETAS_DELEGATE_FS=host` | Delegate the tool-facing filesystem to the editor instead of the local one. |
| `CETAS_DEBUG_WIRE=1` | Write a per-session `<session-id>-wire.jsonl` under `~/.cetas/debug/`. |
| `CETAS_DEBUG_MCP_CATALOG=1` | Write a per-session `<session-id>-catalog.json` under `~/.cetas/debug/`. |

MCP server setup is covered in [MCP](/configuration/mcp/).
